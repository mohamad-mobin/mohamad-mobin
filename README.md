## 👨‍💻 About Me

### 👨‍💻 درباره من

I'm a **Frontend Developer** who enjoys turning ideas into clean, interactive, and responsive web experiences.

من یک **توسعه‌دهنده Frontend** هستم که از تبدیل ایده‌ها به تجربه‌های وب تمیز، تعاملی و واکنش‌گرا لذت می‌برم.

My main focus is the **Vue ecosystem**, especially **Vue.js** and **Nuxt.js**. I care about component architecture, user experience, performance, maintainable code, and the small details that make an interface feel right.

تمرکز اصلی من روی **اکوسیستم Vue**، به‌خصوص **Vue.js** و **Nuxt.js** است. معماری کامپوننت‌ها، تجربه کاربری، عملکرد، کد قابل نگهداری و جزئیات کوچکی که باعث می‌شوند یک رابط کاربری حس خوبی داشته باشد، برای من اهمیت زیادی دارند.

I'm also deeply interested in **Linux**, developer tooling, Git, open-source workflows, and understanding how the tools I use actually work under the hood.

همچنین به **Linux**، ابزارهای توسعه، Git، فرآیندهای Open Source و درک نحوه عملکرد ابزارهایی که استفاده می‌کنم در سطح عمیق‌تر علاقه زیادی دارم.

## 🧠 My Development Philosophy

### 🧠 فلسفه من در توسعه

> **Write code that you can understand six months later.**

> **کدی بنویس که شش ماه بعد هم بتوانی آن را بفهمی.**

I prefer:

ترجیح می‌دهم:

* 🧩 Small and reusable components
  کامپوننت‌های کوچک و قابل استفاده مجدد

* 🧼 Clean and readable code
  کد تمیز و خوانا

* ⚡ Performance without sacrificing maintainability
  عملکرد بالا بدون قربانی کردن قابلیت نگهداری کد

* 🎯 Simple solutions over unnecessary abstraction
  راه‌حل‌های ساده به‌جای abstractionهای غیرضروری

* 🎨 UI that feels good, not just UI that technically works
  رابط کاربری‌ای که حس خوبی داشته باشد، نه فقط رابطی که از نظر فنی کار کند

* 🔍 Understanding the tools instead of blindly using them
  درک کردن ابزارها به‌جای استفاده کورکورانه از آن‌ها
